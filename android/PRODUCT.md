# HBTCP Android 产品约束

这是用户已确认设计的安卓原生实现，后续迭代保持同一套品牌与操作结构。

- 品牌：虎斑老虎与纸飞机，使用 `branding/hbtcp-logo.svg` 原始图形。
- 主色 `#FC8903`；浅色背景 `#FFFDF8`；顶部奶油橘 `#FFE9C8`；文字 `#29251E`。
- 上半屏展示品牌与连接状态，下半屏是操作区，启动按钮在底部拇指区域。
- 主功能只有分流 / 全局、订阅导入、节点选择和启动 / 断开。
- 导入菜单包含订阅链接、扫二维码、从剪贴板导入。
- 未导入节点时显示「导入后选择」，不要添加「自动」二字。
- 节点选择下显示「切换节点无需停止后再启动，直接点击新节点即可」。
- 连接状态来自 daemon 进程消息，不用 UI 动画或按钮状态伪造连接成功。
- 不内置生产订阅、账号或测试节点；测试数据仅存在本地 QA 脚本和模拟器中。
- 使用 v2rayNG / Xray / HEV 已有机制，保留上游许可与来源信息。
