## Android

- 分流 / 全局模式，一键启动与切换节点。
- 支持订阅链接、扫码和剪贴板导入。
- 打开 App 时刷新订阅，自动同步服务端节点变更。
- 内置国内直连与海外代理分流规则。
- Telegram 客服：[@HBTCP_bot](https://t.me/HBTCP_bot)。

通用 APK 适合大多数安卓设备；按处理器架构区分的精简安装包可在版本页面下载。

1.0.4 使用新包名 `com.hbtcp.client`，请安装后重新导入订阅。
